# Calculadora Web (JavaScript + Python)

Calculadora com interface em JavaScript e cálculo feito em Python (Flask).
As expressões são avaliadas com o módulo `ast`, sem usar `eval()`.

## Como rodar

```bash
pip install -r requirements.txt
python app.py
```

Acesse http://127.0.0.1:5000

## Tecnologias

- Python + Flask (backend)
- HTML, CSS e JavaScript (frontend)
